# notebooks/

Working notebooks from the project — Colab session logs, diagnostics, and
troubleshooting scratch used while running experiments (MUSAN diversity, RAFT,
seed variance, standard-CTC reruns, gap-covering, rerank diagnostics, etc.).

They are **kept for provenance**, not as a polished API. The reproducible
entry points are the scripts under [`scripts/`](../scripts) and the per-stage
drivers under [`experiments/`](../experiments); start there. Figures are
regenerated with [`scripts/generate_figures.py`](../scripts/generate_figures.py).
